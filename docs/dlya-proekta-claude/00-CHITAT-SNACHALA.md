# Как подключить память к проекту в Claude (claude.ai → Projects)

1. Создай проект (например, «2young4U — сайт»).
2. **Файлы проекта (Project knowledge) → Добавить** — загрузи все файлы этой папки:
   - `01-pamyat-proekta.md` — **главное**: кто мы, как устроен сайт, весь наш код,
     решения Кристины, что сделано и что ждём;
   - `02-hronologiya-chata.md` — вся наша переписка текстом, по датам (≈1 МБ);
   - код как сейчас на сайте: `SHAPKA-T123.html` («Шапка 1.1»), `glavnaya-hero.html`
     (главная), `podval.html` (подвал), `HEAD-na-sayte-28-10-2026.html` (HEAD),
     `onas-kollekciya-ssylki.html` (ещё не вставлен);
   - документы: `itog-26-10-2026.md` (журнал 26–28.10, что осталось),
     `client-decisions.md`, `kontent-sverka-25-10.md`, `tilda-reference.md`, `url-map.md`.
3. **Инструкции проекта (Set project instructions)** — вставь:

> Ты помогаешь Григорию с сайтом 2young4u.ru на Tilda (бренд 2young4U, заказчица
> Кристина Герман). Сначала прочитай «01-pamyat-proekta.md» — там всё главное.
> Отвечай по-русски, коротко и практично, на «ты». 95 % посетителей — с телефона.
> Григорий сам вставляет код в Tilda: давай готовый код целиком и точные шаги
> (страница, блок, что выделить, что вставить, «Опубликовать все страницы» для
> шапки и подвала). Общий код — «Шапка 1.1» (SHAPKA-T123.html, 15 частей): при
> правке меняй нужную часть и отдавай файл целиком. Пароли и ключи никогда не
> записывай. Сам зайти на сайт ты не можешь — проси скриншоты с телефона.

4. Код может устареть: если Григорий что-то поменял в Tilda без Claude — пусть
   пришлёт свежий код блока или скрин. Самое актуальное — в GitHub
   `grigager-collab/claude`, ветка `claude/tilda-favorite-button-fix-2w5079`.
