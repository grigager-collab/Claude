## 4. 24.10, вечер: общий код «Шапки 1.1» — `head/SHAPKA-T123.html`

Заменяет ВСЁ содержимое блока T123 на «Шапке 1.1» (там был только шрифт).
Части по отдельности: `font-alias-tenor`, `catalog-photo-3x4`, `card-layout`,
`card-extras`, `cookie-popup`. Проверено на живых страницах с вставкой кода:
карточки Ватаным и Volcano на 390/1024/1280/1440/1920, главная, /men/hoodies.

- **Двойные крошки** (скрин заказчицы): скрипт крошек в HEAD при медленной
  загрузке срабатывает раньше стилей Tilda и кладёт крошки внутрь сетки
  названия (`.t780__title-wrapper` — grid) → вторая копия узкой колонкой.
  На быстром интернете не воспроизводится. Решение: все старые копии
  скрыты, одна строка над фото.
- **Размеры в ряд**: старое правило `--variant-box-size` (0,4,0) держало
  56 px — перебито селектором (0,6,0). Один ряд на всех ширинах.
- **ПК-колонки**: сетка была прижата влево, текст 400 px вылезал за колонку
  260 px. Теперь flex по центру, текст 360–440 px. Ловушки: clearfix
  `::before` во flex = лишний отступ; `align-items` только stretch, иначе
  Tilda не «прилепляет» колонку; max-width «липкой» части ставит Tilda сам.
- **Параметры модели**: прочерки → 188 см / XL/L на мужских карточках.
  ⚠️ В HEAD есть ещё попап каталога с «186 см / M» — если товары открываются
  страницами /p/, его не видно.
- **Избранное**: строка «Размер: …» скрыта.
- **Cookie**: окно по центру, «Принять» / «Только необходимые», выбор в
  cookie `t2y_cc` на год. Для будущей Метрики: `window.t2yCookieOK()`.

📌 Найдено попутно: в HEAD движок аккордеонов делает
`observe(document.body)` ещё в `<head>`, где body нет → ошибка в консоли
на каждой карточке. Аккордеоны всё равно строятся (по таймерам). Лечится
заменой `document.body` → `document.documentElement` в последней строке.
