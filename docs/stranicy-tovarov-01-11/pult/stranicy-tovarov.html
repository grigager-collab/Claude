Порядок работы

Один раз, до первой страницы

Загрузить короткие описания в каталог, файл import-kratkie-opisaniya.csv. Текст под «В корзину» Tilda берёт из каталога только в момент привязки товара, поэтому сначала импорт, потом страницы.

  1. «Каталог товаров» → «Импорт» → CSV → этот файл.
  2. «Группировка вариантов товара» → «Группировать по Parent UID».
  3. «Обновить только существующие товары и не создавать новые».
  4. «Заменить имеющиеся изображения у обновлённых товаров» — не ставить. «Заменить только выбранные табы» — тоже.
Ещё не загружены. После загрузки напиши — проверю.

На каждый товар, минуты три

  1. Список страниц → «Костюм с шёлком Ватаным» → «Дублировать».
  2. «Настройки» копии. «Главное»: заголовок и адрес страницы. «SEO» → «Настроить отображение в поисковой выдаче»: заголовок и описание; там же снять «Запретить поисковикам индексировать страницу». «Сохранить».
  3. «Редактировать». Карточка для ПК (T760) → «Контент» → выбрать товар. То же в карточке для телефона (T780). Одинаковых названий много, сверяйся с фото, ценой и артикулом.
  4. Под карточкой — HTML-блок с текстом про шёлковый костюм («…вышитым гербом Татарстана»). «Контент» → стереть весь код → вставить «Блок текстов» → «Сохранить». Второй текстовый блок, про молочную олимпийку, не трогать.
  5. «Опубликовать» и отметить здесь «Сделано».

Когда страницы готовы

Напиши «проверяй». Открою каждую страницу на сайте и отмечу здесь «Проверено» или замечание. Проверять можно и частями.

В конце пришлю файл со ссылками. После него карточки в каталоге будут открывать новые страницы, а не стандартное окно Tilda.
