# Страницы товаров `/p/…` для 78 новых товаров — 01.11.2026

Просьба Григория: сделать страницы для товаров импорта VipAvenue от 01.11.
Вся информация берётся с VipAvenue. Под «В корзину» нужно короткое лаконичное
описание, а в «Детали» — развёрнутое и подробное.

**Пульт:** https://claude.ai/artifact/R9t1YZRMRZmqrUWtf7voEW
- Там по каждому товару есть всё, что вписать и вставить, с кнопками «Копировать».
- Отметку «Сделано» ставит Григорий, «Проверено» или замечание — Claude после
  проверки на сайте.
- Отметки хранятся в базе пульта:
  - `made/<адрес>` — `{made, at}`;
  - `check/<адрес>` — `{state: ok|issue, note, at}`;
  - `meta/import` и `meta/links` — шаги «один раз» и «в конце».

## Что на странице

- **Под «В корзину»** — короткий текст, 1–2 фразы, 101–163 знака.
  - Написан по описанию VipAvenue.
  - Импортом попадает в «Подробное описание» товара в каталоге. Tilda копирует
    его в карточку на странице в момент привязки товара; позже карточка сама не
    обновляется.
- **«Детали»** — полный текст VipAvenue:
  - опечатки поправлены, буква ё на месте;
  - у 37 костюмов и комплектов вторая строка — «В комплекте: олимпийка и брюки»
    и т. п.;
  - в конце — «Страна производства: Россия.»
- **«Ткань, состав, уход»**:
  - состав с VipAvenue (у футболок из комплектов — отдельной строкой, у
    шерсти — подклад);
  - уход как на остальных страницах; у шерсти — уход для шерсти.
- **«Параметры модели на фото»** — с VipAvenue: обхваты и размер на модели,
  например «L (50)».
  - У 7 мужских вещей на VipAvenue параметров нет. Там прочерки, код «Шапки»
    подставляет 188 см и XL/L, как на других мужских страницах.
- **Хлебные крошки** — раздел товара, например «Мужское / Костюмы»,
  «Женское / Олимпийки».
- **SEO:**
  - заголовок 41–62 знака, описание 113–150;
  - на шаблоне стоит «Запретить индексировать», на новых страницах галочку
    снимаем — весь сайт пока закрыт в robots.txt.

## Порядок

1. **Один раз:** `import-kratkie-opisaniya.csv`.
   - Настройки импорта:
     - «Группировать по Parent UID»;
     - ✅ «Обновить только существующие товары и не создавать новые»;
     - ⬜ «Заменить имеющиеся изображения у обновлённых товаров»;
     - ⬜ «Заменить только выбранные табы».
   - Меняется только «Подробное описание». Названия, цены, старые цены,
     остатки (по 10) и артикулы в файле те же, что на сайте 01.11 — сверено по
     всем 78.
2. **На каждый товар** (шаги есть и в пульте):
   1. Дублировать страницу «Костюм с шёлком Ватаным» (`/p/kostyum-shelk-vatanym`).
   2. В «Настройках» копии:
      - «Главное» — заголовок и адрес;
      - «SEO» — заголовок и описание;
      - снять «Запретить поисковикам индексировать страницу».
   3. Привязать товар в T760 (ПК) и T780 (телефон). Сверяться с фото, ценой и
      артикулом: 10 товаров называются «Костюм хлопковый».
   4. В первом HTML-блоке с текстом (про шёлковый костюм, «…гербом
      Татарстана») заменить весь код на блок из пульта. Второй блок, про
      молочную олимпийку, — старый остаток шаблона. Движок берёт первый блок,
      второй ни на что не влияет.
   5. Опубликовать.
3. **Проверка** — Claude открывает страницы на сайте и сверяет:
   - товар привязан (название, артикул, цена);
   - тексты и крошки — из нашего блока;
   - SEO и индексация.
4. **В конце** — импорт ссылок: «Ссылка» каждого товара → `/p/<адрес>`. Файл
   собирается в тот день с остатками и ценами с сайта, чтобы импорт их не
   сбросил. После него карточки каталога открывают новые страницы.
