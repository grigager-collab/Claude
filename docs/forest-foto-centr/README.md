# Forest: ровные фото для страниц товаров (29.10.2026)

**Что было.** На страницах товаров `/p/…` у 18 фото модель стоит левее центра,
на 3–10 %. В карточках каталога (список товаров) фото ровные: первые фото там
заменили 29.10 в 22:56 (МСК).

**Почему страницы не поправились сами.** Галерея на странице товара — это
отдельная копия внутри блоков страницы. Связь блока с каталогом подтягивает
только размеры, цену и наличие, а фото — нет (проверено по коду Tilda). Фото на
странице меняются только в самих блоках.

**На каждой странице два блока товара, у каждого своя галерея:**
- **T760 — для ПК** (стоит выше);
- **T780 — для телефона** (стоит ниже).

**Что сделано.** Модель сдвинута в центр (по корпусу, точность ±0,3 %), масштаб
тот же, ничего не обрезано. Открывшийся край — продолжение того же фона, стыка не
видно. Размер 900×1200, сжатие как у оригиналов. Сравнение — `do-posle.jpg`.

## Имя файла = куда ставить

`tel3_pk2.jpg` → в блоке **телефона** фото **№3**, в блоке **ПК** фото **№2**.
`tel7.jpg` — только телефон, `pk6.jpg` — только ПК. Номера считаются слева
направо в галерее блока, с 1.

## Как заменить (на каждой странице)

1. Открыть страницу товара → блок **T760** (ПК) → «Контент» → галерея.
2. Фото №N: заменить файлом из папки. Если кнопки «Заменить» нет — удалить
   старое, загрузить новое и перетащить его на место №N.
3. То же в блоке **T780** (телефон) — по номерам `tel…`.
4. «Сохранить и закрыть» → «Опубликовать».

## Что не трогать

- **Каталог товаров** — там первые фото уже ровные, остальные фото каталога на
  сайте не показываются (карточка ведёт на страницу `/p/…`).
- **Крупные планы** (логотип, молния, карман, ткань) — там центр не важен,
  оставлены как есть.
