# Доп. цвета на карточке — картинки для Кристины (25.10.2026)

Её вопрос: «Как добавить сюда доп цвета? Они точно есть в тестовых карточках»
(скрин карточки «Олимпийка хлопковая Volcano», красными кружками — где хочет
другие цвета).

## Картинки (1080×1350, для Telegram)

1. `cveta-1-pochemu-odin-cvet.jpg` — почему сейчас один квадратик.
2. `cveta-2-variant-a.jpg` — вариант А: квадратики-ссылки (советуем).
3. `cveta-3-variant-b.jpg` — вариант Б: все цвета внутри одного товара.
4. `cveta-4-sravnenie.jpg` — сравнение, вопрос, какие товары — цвета одной модели.

Карточка с четырьмя квадратиками — живая страница сайта, в строку «Цвет»
подставлены копии штатного квадратика с фото других цветов (`src/shots.js`).
Каталог — плитки раздела /men/hoodies.

## Что выяснено (проверено на сайте)

- Каждый цвет — отдельный товар (своя страница, артикул, 6–7 фото, плитка).
  В строке «Цвет» Tilda показывает варианты только своего товара → квадратик один.
- Цвета одной модели (по названиям, ей подтвердить):
  Олимпийка хлопковая — чёрная, синяя, Ocean, Volcano;
  Олимпийка классическая — Ocean, Space, Volcano;
  Олимпийка с принтом Ватаным — белая (/p/olimpiyka-vatanym), чёрная, синяя.
  Итого 10 товаров → 3 модели; в разделе «Олимпийки и толстовки» 11 плиток → 4.
- Пустой квадратик цвета (к варианту не прикреплено фото): Олимпийка
  хлопковая чёрная и синяя. Остальные 16 товаров — с фото.
- Вариант Б по справке Tilda: «Каждый вариант может иметь собственный
  артикул, изображение, цену, количество» — изображение одно на вариант,
  галерея товара общая (help-ru.tilda.cc/online-store/parameters, /catalog).

## Как пересобрать

Скрипты запускались из рабочей папки, где лежит `pw.js` (запуск Playwright
через прокси): `shots.js` — скрины с сайта в `img/`, `gen.py` — HTML слайдов,
`render.js` — JPEG.
