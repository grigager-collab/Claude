# Корзина: доставка, пожелания, получатель, согласия — 25.10.2026

## Что сейчас (проверено по коду сайта)

- Корзина — **ST100 «Корзина с формой заказа»** (в коде страницы блок `706`,
  метка `tcart`). Лежит в **«Шапке 1.1»** — между Zero-блоком шапки и блоком
  избранного, поэтому она одна на весь сайт. Другой блок не нужен: и доставка,
  и Т-Банк работают именно с ней.
- В форме **три поля**, все обязательные: «Ваше имя», «Ваш e-mail»,
  «Ваш телефон». Почта обязательна — это и нужно Т-Банку для чеков.
- **Поля «Варианты доставки» нет.** Поэтому три варианта, подключённые в
  Настройки сайта → Доставка, нигде не показываются: Tilda выводит их только
  через это поле в режиме «продвинутых настроек» (справка Tilda:
  help-ru.tilda.cc/online-store/shipping, tilda.cc/ru/answers/a/no-delivery-in-cart/).
  Нет доставки в заказе — нет её и в личном кабинете.
- Подпись под кнопкой — без ссылок.

## Что сделать — всё в «Шапке 1.1» → блок корзины → «Контент»

### 1. Доставка
1. «Поля для ввода» → «Добавить поле для ввода» → тип **«Варианты доставки»**.
2. Раскрыть это поле → галочка **«Использовать продвинутый режим настроек»**.
3. «Сохранить и закрыть».
4. Настройки сайта → Доставка → «Настройки» у каждого варианта, цены — как
   в Приложении 2 оферты:
   - «Доставка по г.Казань» — **500 ₽**;
   - «Доставка по РФ» — **600 ₽** (в оферте это СДЭК);
   - «Самовывоз» — **0 ₽**, пункт: Казань, ул. Спартаковская, д. 2, ИТ-парк
     им. Башира Рамеева, по предварительному согласованию.
   В вариантах «по адресу» там же выбираются поля, которые заполняет покупатель
   (адрес и т. п.) — включить нужные.
5. **«Опубликовать все страницы»** — без этого Tilda доставку не покажет.

### 2. Получатель (если получает другой человек)
Справка Tilda не перечисляет поля вариантов доставки. Поэтому:
- если в настройках варианта (шаг 1.4) есть «ФИО получателя» / «Телефон
  получателя» — включить их;
- если нет — добавить в корзину два **необязательных** поля: «Однострочный
  текст» → «Имя получателя» и «Телефон» → «Телефон получателя», подпись:
  «Заполните, если заказ получит другой человек».

### 3. «Ваши пожелания»
- Поле **«Многострочный текст»**, необязательное.
- Название: **«Комментарии (ваши пожелания)»** — в оферте это поле называется
  «Комментарии» (п. 3.4, 4.3, 4.6), так совпадёт и с офертой, и с её просьбой.
- Подсказка в поле: «Изменения модели, вышивка, удобное время доставки…».

### 4. Согласие на рекламу
- Поле **«Чекбокс»**, **необязательное**, галка заранее **не** стоит
  (так требует её документ: не объединять с обязательным согласием).
- Текст — из её документа: «Согласен(на) получать рекламную информацию и
  новости 2young4U»; слова «рекламную информацию» — ссылка на `/soglasie`.
- Название поля: **«Согласие на рекламу (ред. 24.10.2026)»** — оно пишется
  в каждую заявку вместе с датой и временем: это и есть «список, кто поставил
  галку» (раздел «Заявки» в Tilda).

### 5. Подпись под кнопкой — две ссылки
Текст (её вариант, «Оплатить» → «Оформить заказ», как на кнопке):

> Нажимая «Оформить заказ», вы даёте согласие на обработку своих персональных
> данных в соответствии с политикой обработки персональных данных и
> соглашаетесь с условиями договора-оферты.

Ссылки — выделить слова → значок ссылки в редакторе Tilda:
- «политикой обработки персональных данных» → `/politika-obrabotki-persdannyh`
- «договора-оферты» → `/oferta`

⚠️ Для юриста (писал в сводке): с 01.09.2025 согласие на обработку ПД —
отдельно от других документов; для заказа оно не требуется (основание —
договор, п. 5.1.2 её политики).

### 6. Порядок полей
Имя → Email → Телефон → Варианты доставки → (получатель) →
Комментарии → Чекбокс согласия на рекламу → кнопка.

## Проверка после публикации
Добавить товар → корзина: видны три способа доставки, сумма меняется
(+500 / +600 / 0), новые поля на месте. Проверю на сайте сам; оплату — на
тестовом «Подарочном сертификате» за 1 ₽.
