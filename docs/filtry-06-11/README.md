## Порядок

1. **Кристина** отвечает на лист «Вопросы» и, если нужно, правит жёлтые столбцы «… будет».
2. **Claude** делает файл импорта свойств:
   - сначала тест на одном товаре;
   - проверка, что цены, остатки, разделы и фото не задеты;
   - потом все товары.
3. **Григорий** в каждом блоке каталога на 12 страницах добавляет фильтры «Размер», «Сезон», «Капсула», «Стиль». Порядок, как в схеме: цена, размер, сезон, материал, подклад, капсула, стиль. Это можно сделать и до импорта: значения в фильтрах станут чистыми после него.
4. **Claude** снимает номера новых фильтров с сайта и даёт готовые ссылки для слайдов главной. Их меняют в обоих блоках слайдера: ПК `rec2271738031` и телефон `rec2271738541`.
