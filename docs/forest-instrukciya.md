## Шаг 1. Импорт в каталог
1. Каталог товаров → Импорт → CSV → файл `import-forest-zelenyy.csv`.
2. ⚠️ Внизу «Группировка вариантов товара» → **«Группировать по Parent UID»**.
3. Загрузить. Tilda сама скачает фото (1–2 минуты).
4. Проверить: 8 новых товаров, у каждого 4 размера, фото на месте.

## Шаг 2. Страницы /p/… (на каждый товар)
1. Скопировать готовую страницу карточки (например /p/olimpiyka-hlopkovaya-ocean-siniy).
2. Настройки страницы → адрес из таблицы выше, заголовок — название товара.
3. В блоке карточки → Контент → выбрать новый товар Forest.
4. В HTML-блоке с текстами → выделить всё → вставить кусок из `bloki-forest.html`
   (ищи по адресу /p/…).
5. Опубликовать.
