---

## ПРАВИЛА ИМЕНОВАНИЯ

1. **Только латиница**, нижний регистр. Никакой кириллицы.
2. **Разделитель — дефис** `-`, не подчёркивание.
3. Без расширений файлов, без параметров, без заглавных букв.
4. **Коротко и понятно:** `/men/hoodies`, а не `/men/olimpiyki-i-tolstovki`.
5. **Адрес задаётся один раз и не меняется.** Опубликованный URL — это ссылка,
   которой могли поделиться, которую мог проиндексировать поиск и закэшировать
   Telegram. Менять — только с редиректом со старого адреса.
6. Без завершающего слэша, кроме системных `/members/`.

## КАРТОЧКИ ТОВАРОВ

**Формат: `/p/<slug>`** — плоский, без категории в адресе.

Товар может переехать между категориями или попасть в распродажу.
При плоском адресе ссылка **никогда не ломается** — главный задел на будущее.

Slug генерируется автоматически конвертером фида: транслит названия + цвет.
Пример: «Олимпийка классическая Space», Синий → `olimpiyka-klassicheskaya-space-siniy`.

## СВЯЗЬ С ОСТАЛЬНЫМ

**Меню** правится в ДВУХ местах, оба на «Подвале 1.1»:
① десктоп — Zero-блоки попапов `#formanpopup` / `#forwomenpopup`;
② мобильный — блок **ME403**, Контент → «Список пунктов меню».
Адреса писать **относительными** — полные ломаются в предпросмотре.

⚠️ Верхним пунктам («Мужское») ссылку поставить **нельзя**: поле URL занято
крючком попапа. Переход на витрину — отдельной строкой «Всё мужское» внутри меню.

**Как задать адрес:** Настройки страницы → «Адрес страницы (URL)» → путь без
домена и без ведущего слэша (`men/hoodies`) → Сохранить → **Опубликовать**.
До публикации новый адрес не существует.
