# КАК ЭТО ЧИТАЕТСЯ

В листе **«Коллажи»** 16 строк набраны **чёрным** шрифтом (остальные — серым,
они пока не в работе). Каждая строка это **модель × цвет**, а не артикул:
заливка первой ячейки задаёт цвет ткани, текст — внутреннее название силуэта.

Артикулов там нет вообще. Расшифровать удалось благодаря «Справочнику моделей».

# ОТКУДА ЧТО БЕРЁТСЯ ПРИ ИМПОРТЕ

Всё, кроме разделов, тянется из фида автоматически:

| Поле Tilda | Источник в фиде |
|---|---|
| Название | «Название товара» |
| Описание | «Описание товара», очищенное от дефисов-списков |
| Фото | «Фото1»–«Фото10», до 10 ссылок |
| Цена | «Цена» |
| Размеры | строки фида по одной на размер |
| Цвет | «Цвет», с приведением написания (Черный → Чёрный) |
| Материал | **первое слово** из «Состава» — для фильтра |
| Раздел | «Категория товара» через таблицу соответствий |

Остаток ставится **10** на размер по решению заказчицы, хотя в фиде есть реальный.
Сезон — **«Всесезон»**, кроме Winter tale → «Зима».
