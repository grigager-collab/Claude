# 🔴 СЛОМАНО — работает, но неправильно

## 1. Ссылка на шрифт ведёт не туда

Настройки → Шрифты → Google Fonts → CSS LINK:

```
https://fonts.google.com/specimen/EB+Garamond?query=garamond   ← витрина шрифта
https://fonts.googleapis.com/css2?family=EB+Garamond:wght@400  ← как должно быть
```

Браузер на каждой из 46 страниц скачивает **195 790 байт HTML** вместо
980 байт CSS, пытается прочитать как стили, не может, выбрасывает.
И это **блокирует отрисовку**. При этом EB Garamond на сайте не используется
нигде — в стилях только Tenor Sans, Raleway и Arial.

**Очистить поле.** Raleway подключён отдельной правильной ссылкой, Tenor Sans
идёт из библиотеки Tilda — не пострадают.

## 2. Google Analytics мёртв с 2023 года

В поле `UA-147736966-1` — это **Universal Analytics**, отключённый Google
в июле 2023. В коде сайта честно выполняется `ga('send','pageview')`
в сервис, которого нет. Нужен GA4, его идентификатор вида `G-XXXXXXXXXX`.

## 3. В поле Tag Manager вставлен тот же UA-номер

Контейнер GTM всегда вида `GTM-XXXXXXX`. Сейчас на каждой странице уходит
запрос `googletagmanager.com/gtm.js?id=UA-147736966-1` и висит невидимый
`<iframe>` с тем же мусором. Контейнер не находится.
**Если GTM не нужен — очистить поле.**

## 4. AmoCRM: Приобрели с сайта — 🔴 Заблокировано

Заказы в AmoCRM не уходят. Переподключить или удалить интеграцию.

## 5. Страницы 404 не существует

Настройки → Ещё → «СТРАНИЦА ОШИБКИ 404: **Не выбрано**». А битые ссылки
есть и они сквозные. Человек, нажавший «Возврат» в подвале, видит голую
страницу Tilda — без шапки, логотипа и меню. Тупик.

# 🟡 ПРОВЕРИТЬ — снаружи не видно

## Почтовые уведомления об успешном заказе

Платёжные системы → внизу «Настроить» → два пункта:
- Почтовые уведомления об успешном заказе
- Проверка цены товара и доставки перед переходом к оплате

**Первый — самое важное из всего списка.** Без него покупатель оплатит
и не получит подтверждения. Второй защищает от устаревшей цены в корзине.

## Оплата ни разу не проходила до конца

В CRM все тестовые заказы со статусом «Не оплачен». Значит цепочка
корзина → банк → возврат на сайт → письмо → статус «Оплачен»
**не проверена ни разу**. Это главный пункт перед продажами.
