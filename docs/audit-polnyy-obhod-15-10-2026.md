## ⚠️ ОШИБКА ПЕРВОЙ ВЕРСИИ ЭТОГО ОТЧЁТА

Здесь было написано, что на `/p/olimpiyka-vatanym` видимым текстом выведены
служебные комментарии из файла блоков. **Это неверно, страница в порядке.**

Как получилась ошибка: я снимал видимый текст, вырезая теги регуляркой
`<[^>]+>`, но **не вырезав сначала комментарии**. Комментарий `<!-- … -->`
содержит внутри `>` — например в строке `data-crumb-url="/men/hoodies">` —
регулярка спотыкалась на нём и отдавала обрывки комментария как текст
страницы. Браузер комментарии не показывает.

Второй промах: вывод «ссылок с сайта нет, значит страница-сирота». Плитки
каталога Tilda рисует джаваскриптом, поэтому обход по статическим ссылкам
**не видит ни одной карточки товара**, включая рабочие. Проверка негодная.

📌 **Вывод: вырезать комментарии ПЕРЕД снятием тегов. И не делать выводов
об осиротевших страницах там, где ссылки рисует скрипт.**

### Что на этой странице действительно есть

Мелочь: в блоке продублирована строка атрибутов — после закрывающей
`>` тега `<div class="t2y-acc-source" …>` идёт второй набор
`data-crumb-parent=… data-crumb-name=… data-crumb-product=…>` простым
текстом. Лежит внутри скрытого контейнера, поэтому не видно, но это мусор
от вставки. Почистить при случае.

Сама страница рабочая: артикул 21260505, молочная олимпийка, шесть размеров,
аккордеоны раскрываются, крошки на месте.

## 🔴 Четыре вещи, без которых SEO не взлетит

Сайт технически готов к открытию индексации, но поисковику нечего взять.

### `sitemap.xml` пустой — 0 байт

```
sitemap.xml        код 200, 0 байт     ← ни одного адреса
sitemap-store.xml  код 200, 22 адреса  ← только товары
```

То есть `/men`, `/women`, `/about`, `/delivery` и прочие разделы поисковик
о себе не узнает. Товарные — узнает.

### Мета-описаний нет **ни на одной** из 46 страниц

В выдаче поисковик подставит случайный кусок текста вместо продающего
описания. Заполняется: Настройки страницы → SEO → Описание.

### Заголовка `<h1>` нет **ни на одной** из 46 страниц

Во всём коде встречается один `<h3>` и ни одного `<h1>`/`<h2>`. Для
поисковика h1 — это «о чём страница»; сейчас такого сигнала нет нигде.
Типично для сайтов на Zero Block: текст там рисуется обычными блоками.
Лечится в настройках текстового элемента — выбрать тег `H1` для названия
товара на карточке и для названия раздела в каталоге.

### `alt` нет **ни у одной** из 468 картинок

100%. Это и поиск по картинкам, и доступность — отсюда же замечания
Lighthouse про «текст ссылок неразличим для программ чтения с экрана».
