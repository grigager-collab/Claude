### 1. Общие положения

1.1. Настоящая Политика определяет порядок обработки персональных данных
`[ИП / ООО «…»]` (далее — «Оператор») и меры по обеспечению их безопасности.

1.2. Политика разработана в соответствии с Федеральным законом от 27.07.2006
№ 152-ФЗ «О персональных данных».

1.3. Политика применяется ко всей информации, которую Оператор может получить
о посетителях сайта 2young4u.ru.

### 3. Какие данные обрабатываются

**3.1. При оформлении заказа:**

- фамилия, имя
- номер телефона
- адрес электронной почты
- адрес доставки
- состав и сумма заказа

**3.2. При регистрации в личном кабинете:**

- имя, адрес электронной почты, номер телефона
- история заказов
- сохранённые адреса доставки

**3.3. Автоматически при посещении сайта:**

- IP-адрес, тип браузера и устройства
- дата и время обращения
- страницы, которые посетил пользователь
- источник перехода

Данные пункта 3.3 собираются сервисами веб-аналитики и обрабатываются
в обезличенном виде.

**3.4. Оператор НЕ обрабатывает** специальные категории персональных данных
(раса, политические взгляды, состояние здоровья, убеждения) и биометрические
данные.

**3.5. Оператор НЕ получает и НЕ хранит данные банковских карт.** Оплата
проводится на стороне платёжного сервиса.

| Рассмотрение обращений и возвратов | имя, телефон, почта |
| Улучшение работы сайта | обезличенные данные посещений |
| Рассылка (только с отдельного согласия) | почта |

### 6. Кому передаются данные

6.1. Оператор передаёт данные третьим лицам **только в объёме, необходимом
для исполнения заказа**:

- **службам доставки** — имя, телефон, адрес получателя;
- **платёжному сервису** — сумма заказа и контактные данные для чека;
- **сервису сайта (Tilda)** — в объёме, необходимом для работы сайта.

6.2. Оператор **не продаёт и не передаёт** персональные данные третьим лицам
в рекламных целях.

6.3. Передача данных государственным органам осуществляется только
по основаниям, предусмотренным законодательством.

### 7. Сроки хранения

7.1. Данные хранятся не дольше, чем этого требуют цели обработки.

7.2. Данные заказов хранятся в течение срока, установленного законодательством
для хранения документов бухгалтерского учёта.

7.3. Данные личного кабинета хранятся до удаления учётной записи
пользователем или по его требованию.

7.4. По достижении целей обработки данные уничтожаются или обезличиваются.

- требовать уточнения, блокирования или уничтожения данных, если они неполные,

10.2. Пользователь может отключить cookie в настройках браузера. При этом часть
