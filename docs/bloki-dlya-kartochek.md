# Блоки для страниц карточек

_Собрано из товарного фида. На каждый товар — готовый кусок для блока T123 на его странице._

**Как пользоваться:** на странице карточки добавить блок «Другое → HTML-код» и вставить соответствующий кусок. Движок аккордеонов и крошек уже в HEAD, здесь только тексты.

⚠️ «Параметры модели на фото» фид не содержит — там заглушка, её надо заменить реальными данными со съёмки.
