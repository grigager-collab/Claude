## 1.1 Очистить битую ссылку на шрифт ✅

**Настройки сайта → Шрифты → вкладка Google Fonts → поле CSS LINK**

Там стоит `https://fonts.google.com/specimen/EB+Garamond?query=garamond`.
Это адрес страницы-витрины, а не файла стилей. Браузер скачивает 63 КБ

**не рисует страницу**.

**Стереть поле целиком.** Поля «Шрифт для заголовков» (Tenor) и «Шрифт
для текста» (Raleway) не трогать.

⚠️ После публикации глянь главную и карточку товара. Raleway подключён
отдельной правильной ссылкой, Tenor Sans идёт из библиотеки Tilda —
пострадать не должны. Но если где-то в Zero Block кто-то вручную выбрал
Garamond, там шрифт сменится на запасной. Тогда вернёшь ссылку,
но правильную: `https://fonts.googleapis.com/css2?family=EB+Garamond:wght@400;600`

## 1.2 Очистить поле Google Tag Manager ✅

**Настройки сайта → Аналитика → GOOGLE TAG MANAGER ID**

Там `UA-147736966-1`. Контейнер GTM имеет вид `GTM-XXXXXXX`. Сейчас

**Стереть поле.** Если позже понадобится GTM — заведёте контейнер

## 1.3 Включить показ системного шрифта при загрузке ✅

**Настройки сайта → Шрифты → внизу «Продвинутые настройки»**

Сейчас, пока грузится шрифт, текст не виден вообще. С галочкой текст

## 1.4 Включить защиту от подмены контента ✅

**Настройки сайта → Ограничить доступ → Дополнительные серверные заголовки**
→ **«Включить защиту от подмены контента»**

Проверил: сервер не отдаёт `x-content-type-options: nosniff`. Включение

## 3.1 (архив) 15.10.2026: покупателям письма НЕ уходят

**Настройки сайта → Платёжные системы → «ОБЩИЕ НАСТРОЙКИ» → Настроить**

В разделе «Уведомления **для покупателей** о сделанном заказе» поле
**«СЕРВИС ДОСТАВКИ ПИСЕМ» пустое**.

⚠️ Не путать с интеграцией `Email: 2young4U.sales@gmail.com` в разделе
«Формы» — та шлёт уведомления **магазину**. То есть вы о заказе узнаёте,
а покупатель не получает ничего: ни подтверждения, ни состава, ни суммы.

### Что требует Tilda

Два условия, написанные в её же окне:
1. ящик должен быть **новый и отдельный**, не личный и не рабочий;
2. «сервис работает **только с почтой на вашем домене**».

Варианта подключения два: **«Почтовый сервер»** (обычный SMTP) и
**SendGrid** (американский, с оплатой из России морока). Берём первый.

### Сколько это стоит

Бесплатной почты на домене в 2026 не осталось:
- Яндекс 360 для бизнеса — бесплатный тариф отключён в 2023,
  минимальный ~300 ₽/мес за ящик
- VK WorkSpace — от ~112–199 ₽/мес, цены в обзорах расходятся

⚠️ Оба сервиса закрывают бесплатный доступ по SMTP (пишут про июнь 2026,
данные из обзоров, не с официальных сайтов). **При покупке прямо спросить,
входит ли в тариф доступ по SMTP для внешнего сервиса** — он и нужен Tilda.

### Сначала попробовать Gmail — это быстрее

Новый Gmail закрывает первое требование, но не второе. **Почему Tilda
требует домен — я не выяснил**: если письма уходят через SMTP самого
Google, с доставкой проблем быть не должно.

Рядом есть кнопка **«Отправить тестовое сообщение на свой email»** —
она даёт точный ответ за три минуты, без оформления заказа:

1. Завести новый Gmail, например `2young4u.orders@gmail.com`
2. Включить двухфакторную аутентификацию → создать **пароль приложения**
   (обычный пароль SMTP не примет)
3. В Tilda: сервер `smtp.gmail.com`, порт `465`, логин — полный адрес,
   пароль — тот самый пароль приложения
4. Поставить галочку и нажать «Отправить тестовое сообщение»

Пришло — работает. Не приняла адрес — значит проверка домена жёсткая,

## 3.1a Две проверки — включить, не дожидаясь почты ✅

В том же окне, оба списка по три варианта. Ставить **средний**:

| | |
|---|---|
| Уровень проверки цены доставки | **«Только помечать в заявке»** |
| Уровень проверки скидки | **«Только помечать в заявке»** |

Строгий вариант («не продавать товар») защищает лучше, но заблокирует
оформление при любом расхождении — например, если заказчица поправит
настройки доставки, пока у кого-то открыта корзина. Покупатель упрётся
в стену и уйдёт. Средний ловит то же самое, но ставит метку в заказе
вместо блокировки. Переключить на строгий — через месяц продаж,
если меток не будет.

Третий список, «Уровень проверки товаров из блоков», трогать не надо:
Tilda тут же пишет, что товары из Каталога проверяются всегда,
а у нас все товары из Каталога.
